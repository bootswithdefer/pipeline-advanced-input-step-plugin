Optional caption for a third "skip" button, offered alongside "proceed" and "abort". When set, choosing it resumes the pipeline with the configured skip return value (see skipValue) instead of proceeding normally or aborting the build. Leave empty to offer only proceed and abort.

Usage: def result = advancedInput message: 'Apply the plan?', ok: 'Apply', skip: 'Skip apply', cancel: 'Abort'

Which will look like: 

        Apply the plan?
        Apply, Skip apply or Abort
