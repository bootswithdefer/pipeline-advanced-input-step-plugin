The value returned to the pipeline when the skip outcome is chosen. Defaults to SKIPPED. Only meaningful when a skip caption is set. The pipeline can branch on it: 

        def result = advancedInput message: 'Apply the plan?', ok: 'Apply', skip: 'Skip apply', skipValue: 'SKIP'
        if (result == 'SKIP') {
            echo 'User chose to skip the apply'
        }
